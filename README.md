
# Mobile WebView & Deep Link PoC Lab

A collection of reusable Proof-of-Concept (PoC) pages for authorized Android and iOS mobile application security testing.

## Features

- JavaScript execution validation
- WebView redirect testing
- HTML file picker testing
- Deep Link landing page testing
- Deep Link parameter inspection

## Live Demo

https://nurbayram.github.io/webview-poc/

## Test Pages

| Test | Path |
|------|------|
| JavaScript Execution | `/webview/javascript/` |
| WebView Redirects | `/webview/redirects/` |
| File Upload | `/webview/file-upload/` |
| Deep Link Landing | `/deeplink/landing/` |
| Deep Link Parameters | `/deeplink/parameters/` |

## Security Notice

This repository is intended for authorized security testing and educational purposes.

The PoC pages do not collect credentials, transmit selected files, or exfiltrate user data.
